# The Robot Apology

A small Python program (stdlib only) that writes a two-line robot confession
to `/output/entry.txt`: one sentence owning a specific mistake, one naming
the lesson and the fix that follows from it.

## Run

```sh
python3 main.py
```

The output path defaults to `/output/entry.txt` and can be overridden with
the `OUTPUT_PATH` environment variable.
